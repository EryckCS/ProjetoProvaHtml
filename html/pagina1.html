O que é HTML?

Explicação

HTML é uma linguagem de marcação

HTML (HyperText Markup Language) é a linguagem de marcação padrão usada para criar e estruturar o esqueleto de páginas na internet, organizando elementos como textos, imagens e links por meio de códigos chamados tags para que os navegadores saibam exatamente como exibir o conteúdo do site.

Conceito

O conceito do HTML é ser a linguagem de marcação padrão da web, servindo como o esqueleto estrutural de qualquer página na internet. Ele não é uma linguagem de programação (pois não possui lógica ou cálculos), mas sim uma ferramenta para descrever o que é cada elemento de um site para o navegador.
